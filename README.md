# Reconhecimento de Movimentos de Braço - TCC

Projeto de Visão Computacional desenvolvido em Python utilizando OpenCV e MediaPipe para deteção e rastreio de movimentos de braço.

## 🛠️ Tecnologias Utilizadas
* **Python 3.11**
* **OpenCV**
* **MediaPipe**

   cd TCC-Prototipo-VisaoCompucional
